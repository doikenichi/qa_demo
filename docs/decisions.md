# Decisions log

Relocated here from `appointment-booking-project.md` once `docs/` existed, as that file committed.
The specification links to this file. No row is reworded, reordered, or deleted on move.

Record project decisions here so future work uses the same assumptions.

**This log is history, not guidance.** It exists to show how the project reasoned.
Nobody should ever need it to know what to build: behavior comes from
[Behavior specification](../appointment-booking-project.md#behavior-specification),
ownership and evidence from the
[requirement tables](../appointment-booking-project.md#requirements-and-traceability),
wire shapes from `contracts/openapi.yaml`.
If a rule can only be found here, it is in the wrong place.

Rows are never deleted or edited away — the history is part of what this document demonstrates
— so the `Status` column says which version is current. `Current` means the row still holds as
written. `Superseded` means a later row replaced it. `Amended` means part of the row still holds
and the named later row changed the rest.
